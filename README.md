# موقع ياسمين محمد سعيد

موقع عربي بسيط للحجز باستخدام Google Apps Script وGoogle Calendar، دون حزم خارجية.

## التطوير المحلي

```sh
python3 -m http.server 8000 --bind 127.0.0.1
node --test tests/booking.test.cjs
```

التشغيل المحلي يعرض الواجهة فقط. الاختبارات تحاكي خدمات Google؛ لا تثبت الاتصال الحقيقي أو سلوك المتصفح.

## النشر والحجز الحقيقي

1. أنشئ مشروع Google Apps Script، وأضف محتوى `Code.gs`، وملف HTML باسم `index` من `index.html`.
2. اضبط المنطقة الزمنية للمشروع على `Africa/Cairo`. يستخدم التحقق من المواعيد توقيت القاهرة صراحة.
3. راجع `CALENDAR_ID` ومدة الجلسة والخدمات والساعات في الباك إند، وطابقها مع `CONFIG` في الصفحة. الجمعة إجازة، والحجز خلال 60 يومًا وبمهلة 30 دقيقة.
4. أضف رقم واتساب الحقيقي بصيغة دولية دون `+` والعنوان والصورة إلى `CONFIG`. الرقم الفارغ يخفي روابط واتساب. أضف صور الشهادات الصحيحة أو روابط صور مستضافة؛ Apps Script لا يستضيف مجلد الصور المحلي تلقائيًا.
5. انشر Web app ينفذ بصلاحية مالك تقويم العيادة، وحدد جمهور الوصول المناسب، وامنح صلاحيات التقويم. افتح رابط النشر نفسه؛ الصفحة تستخدم `google.script.run` لتلقي تأكيد فعلي دون مشاكل CORS. لا يلزم `scriptUrl` لهذا المسار.
6. جرّب حجزًا اختباريًا وتحقق من ظهور حدث واحد في التقويم، ثم حاول نفس الميعاد وتحقق من رفضه. جرّب فشل الاتصال وتأكد من عدم ظهور تأكيد نجاح. احذف الحدث الاختباري يدويًا بعد الانتهاء.
7. عند التحديث أنشئ إصدار نشر جديد. لا تضع أسرارًا في الصفحة أو المستودع.

الاستضافة الخارجية مع `scriptUrl` تحتاج مسارًا يسمح بقراءة استجابة JSON عبر CORS؛ لا تستخدم `no-cors` ولا تعتبر اكتمال الإرسال تأكيدًا للحجز. المسار الموصى به حاليًا هو استضافة Apps Script.

قفل السكربت يمنع تعارض الطلبات المارة بهذا المشروع؛ التعديلات اليدوية أو المشاريع الأخرى على التقويم لا تشارك نفس القفل. عند انقطاع الاتصال بعد إرسال الطلب، تحقق من التقويم قبل إعادة المحاولة. إتاحة الحجز للعامة تحتاج متابعة إساءة الاستخدام وحصص Google. لا يوجد تحقق آلي حاليًا من ملكية رقم الهاتف.
